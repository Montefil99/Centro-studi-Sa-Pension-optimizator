Deploy · Open Source

Pubblica su GitHub Pages

Rendi il tuo advisor online in 5 minuti. Gratis, zero server, aggiornamenti con git push.

  • 1

    Crea repository GitHub

    github.com/new → nome pensioniq-pro → Public → Create repository

  • 2

    Carica i file

    "uploading an existing file" → trascina index.html e README.md → Commit changes

  • 3

    Abilita GitHub Pages

    Settings → Pages → Deploy from branch → main → / (root) → Save

  • 4

    Online in 2 minuti!

    Il sito sarà live su tuonome.github.io/pensioniq-pro

Comandi Git (alternativa drag&drop):

# Init e primo push
git init && git add .
git commit -m "init: PensionIQ Pro"
git remote add origin https://github.com/
USERNAME/pensioniq-pro.git
git push -u origin main

# Aggiorna dopo modifiche
git add . && git commit -m "update"
git push
⚡ Pro tip: Per il backend Python con yfinance e Chronos, usa Hugging Face Spaces (gratuito, GPU disponibile) oppure un VPS con python main.py portafoglio.xlsx — vedi cartella backend/.
