Deploy & Open Source

Pubblica su GitHub Pages

Rendi il tuo optimizer accessibile online in 5 minuti — gratis, zero server.

  • 1

    Crea repository GitHub

    Vai su github.com → New Repository. Nome suggerito: pensioniq-optimizer. Scegli Public.

  • 2

    Carica i file

    Trascina tutti i file del progetto (index.html + cartella src/) nel repository. Oppure usa git.

  • 3

    Abilita GitHub Pages

    Settings → Pages → Source: Deploy from branch → Branch: main → Folder: / (root) → Save.

  • 4

    Il sito è online!

    Dopo ~2 min il sito sarà su tuonome.github.io/pensioniq-optimizer. Condividilo!

Comandi Git (alternativa drag&drop):

# 1. Inizializza il repository locale
git init
git add .
git commit -m "init: PensionIQ optimizer"

# 2. Collega a GitHub e carica
git remote add origin https://github.com/
TUO_USERNAME/pensioniq-optimizer.git
git branch -M main
git push -u origin main

# 3. Aggiornamenti futuri
git add . && git commit -m "update"
git push

⚡ Tip: Aggiungi un file README.md con la descrizione del progetto per renderlo più professionale su GitHub. Il backend Python funziona separatamente — per il forecast online considera Hugging Face Spaces (gratuito).
